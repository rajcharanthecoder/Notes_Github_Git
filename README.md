# Git and GitHub Commands Guide

## 📖 Overview

This repository contains a comprehensive guide to everyday Git and GitHub commands. Whether you're a beginner learning version control or an experienced developer looking for quick references, this guide covers essential commands with detailed explanations, use cases, and practical examples.

## 📋 What's Included

The `gitcommands.md` file includes:

- **40+ Essential Git Commands** - From basic operations to advanced workflows
- **GitHub CLI Integration** - Commands for managing repositories, pull requests, and issues
- **Detailed Explanations** - Each command includes description, use case, and examples
- **Real-world Scenarios** - Practical examples you can apply immediately

## 🚀 Quick Start

1. **Clone this repository:**
   ```bash
   git clone https://github.com/your-username/git-commands-guide.git
   cd git-commands-guide
   ```

2. **Open the guide:**
   - Open `gitcommands.md` in your preferred markdown viewer or text editor
   - Use the table of contents to navigate to specific commands

## 📚 Command Categories

### Basic Git Operations
- Repository initialization and status checking
- Staging and committing changes
- Viewing history and differences

### Branch Management
- Creating, switching, and merging branches
- Rebasing and conflict resolution

### Remote Repository Operations
- Connecting to GitHub and other remotes
- Pushing, pulling, and fetching changes

### Advanced Features
- Undoing changes (reset, revert, restore)
- Stashing work in progress
- Tagging releases
- Debugging with bisect

### GitHub CLI Tools
- Repository management
- Pull request workflows
- Issue tracking

## 💡 Usage Tips

- **Bookmark frequently used commands** for quick reference
- **Practice in a test repository** before using advanced commands
- **Use `git status`** frequently to understand your repository state
- **Commit often** with clear, descriptive messages
